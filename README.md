# ☕ Expense Tracker
 
A simple, good-looking expense tracker in a single HTML file. No installs, no server, no sign-up.
 
## Features
 
- Add expenses with an amount, category, note and date
- Month-wise view with ◀ ▶ arrows
- Monthly budget with a progress bar
- Spending breakdown by category
- Edit or delete any expense
- Add your own categories
- Separate profiles by name, with an optional 4-digit PIN
- Light and dark (espresso) theme
- Export and import a backup file
## How to use
 
1. Open the live site, or open `index.html` in any browser.
2. Type your name to open your profile.
3. Add your expenses and watch your spending add up.
## Where is my data stored?
 
Everything is saved in your own browser (localStorage). Nothing is sent to a server.
 
- Data stays on the device and browser you used.
- Clearing browser data will erase it, so use **Export backup** now and then.
- The PIN keeps casual users out but is not real security.
## Host it yourself
 
1. Fork or upload `index.html` to a GitHub repository.
2. Go to **Settings → Pages**.
3. Set the source to **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Open the link GitHub gives you.
## Built with
 
HTML, CSS and vanilla JavaScript.
